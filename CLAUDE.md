# Signal — working notes for Claude

## Prompt log

Keep `PROMPT_LOG.md` up to date. After each significant feature implementation or design decision, append an entry at the bottom (entries stay chronological) with these headings:

- **Request:** the user's original request, quoted where possible
- **Implementation:** what was built or changed, with the commit hash
- **Problems:** what went wrong or got in the way
- **Feedback:** what the user said about the result
- **Decision:** what was finally decided

Small fixes and questions don't need an entry.
